## 📋 下一步操作

### 主人需要做的：

1️⃣  注册 GitHub 账号
   访问: https://github.com/signup

2️⃣  创建新仓库
   仓库名建议: insulation
   可见性: Public (需要 Actions)

3️⃣  运行推送脚本
   cd /root/.openclaw/workspace/repos/insulation
   ./push-experiments.sh https://github.com/<你的用户名>/insulation.git

4️⃣  启用 GitHub Actions
   访问: https://github.com/<你的用户名>/insulation/settings/actions
   选择: "Allow all actions and reusable workflows"

5️⃣  触发构建
   方式 1 (自动): 推送后自动触发
   方式 2 (手动): 访问 Actions 页面 → experiment-build → Run workflow

6️⃣  下载构建产物
   访问: https://github.com/<你的用户名>/insulation/actions
   点击最新的 workflow run
   下载 Artifacts:
     - insulation-experiment-exp-a-no-boot-guard-rootless-packages
     - insulation-experiment-exp-a-no-boot-guard-roothide-packages
     - (同理 exp-b, exp-c)
