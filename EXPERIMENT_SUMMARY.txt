1. 注册 GitHub 账号
2. 创建新仓库（例如：username/insulation）
3. 运行推送脚本：
   ```bash
   cd /root/.openclaw/workspace/repos/insulation
   ./push-experiments.sh https://github.com/username/insulation.git
   ```
4. 在 GitHub 仓库启用 Actions
5. 触发构建（自动或手动）
